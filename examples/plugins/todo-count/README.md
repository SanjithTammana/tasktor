# todo-count (example plugin)

Counts open TODO lines (`TODO …`, `- [ ] …`) in one text file and shows the count and the first five.

Install: copy this folder to `%LOCALAPPDATA%\Tasktor\plugins\todo-count\`, open Tasktor → Settings → Plugins, enable it
(the consent dialog shows the exact command line), then set **File**.

It reads only the file you choose and uses no network. See `docs/plugins.md` for the contract.
